# Rock Paper Scissors (UI Version)

## 🧠 What I Learned

This project was a continuation of the console-based Rock Paper Scissors game, now brought to life with a fully interactive user interface using **HTML, CSS, and JavaScript**. I learned how to connect logic with UI and handle user interactions efficiently through DOM manipulation and event handling.

## 🚀 What I Built

- Created a clean and responsive **UI layout** with:
  - A navigation section displaying **player** and **computer scores**.
  - A **main game area** with buttons for “Rock”, “Paper”, and “Scissors”.
  - A **result display box** to show the outcome of each round and the final winner.

- Added **event listeners** to handle button clicks and trigger the `playRound()` function dynamically.
- Refactored old code from the console version to make it modular and UI-friendly.
- Implemented **multi-round gameplay**, where the score updates in real-time and the winner is announced when a player reaches 5 points.
- Practiced clean and maintainable DOM manipulation by dynamically updating the UI instead of using `console.log()`.

## 🧩 Key Concepts Practiced

- **DOM Manipulation:** Selecting and updating HTML elements programmatically.
- **Event Handling:** Adding event listeners for user interactions.
- **Event Delegation & Propagation:** Understanding capturing, targeting, and bubbling phases.
- **State Management:** Keeping track of scores and game progress.
- **Code Refactoring:** Separating logic (`playRound`, `playGame`, `printScore`) for clarity and maintainability.

## ⚙️ Future Improvements
